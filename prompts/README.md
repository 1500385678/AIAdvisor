## 每条 prompt 模板的格式

```markdown
# <标题>

> 场景:<一句话说明>
> 适用模型:<Claude / GPT / Gemini / 通用>
> 难度:<⭐ / ⭐⭐ / ⭐⭐⭐>
> 作者/日期:<姓名> · <YYYY-MM-DD>

## 提示词
...

## 适用边界
- 适用:...
- 不适用:...
- 已知坑:...

## 迭代记录
| 版本 | 日期 | 变更 |
|---|---|---|
| v1.0 | YYYY-MM-DD | 首版 |
```

---

## 命名规则

- 文件名:`<场景简述>.md`,中文,≤ 20 字
- 内部用 `<编号>-<名称>.md` 仅在目录已满 10 条时启用
- 同一 prompt 多个变体:在同一文件内用 `## 变体 A/B/C` 区分,不拆多文件
